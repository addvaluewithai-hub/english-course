# Learner Test v1

Status: TEST-001 working package for the final `U1-L03` gold lesson.

This folder contains the minimum ethical kit needed before a real learner session:

- `PROTOCOL.md`: participant, allocation, facilitation, scoring, and decision rules;
- `CONSENT_AR.md`: plain-Arabic information and consent script;
- `FACILITATOR_CHECKLIST.md`: the before/during/after-session checklist;
- `ANALYSIS_RUNBOOK.md`: validation, dry-run, real-evidence, and aggregate commands;
- `START_HERE_AR.md`: Arabic recruitment text and the shortest real-session workflow;
- `success-thresholds.json`: the numeric hypotheses that must be fixed before data;
- `session-record.schema.json`: the de-identified record contract; and
- `session-record.template.json`: a blank, non-answer-bearing record.

The clickable lesson remains at `prototype/gold-lesson/index.html`. The paired observer
form is `prototype/gold-lesson/observer.html`. Both run locally with no account,
network, microphone, database, or analytics service.

The test is about the lesson, not the participant. No raw answer, transcript, audio,
video, full name, phone number, or exact address belongs in the default record.

TEST-001 means the test is ready to run. It does not mean learner evidence exists.
Observed sessions and the resulting go/revise/stop decision belong to TEST-002.
