# First Ten Progression Pilot v1

This folder defines the ethical progression pilot for the actual A1 lessons 1–10.
It supersedes immediate collection with the earlier one-gold-lesson instrument while
retaining its consent, privacy, fresh-mastery, and synthetic-evidence protections.

The pilot asks whether the sequence works across days: comprehension, independent use,
recycling, delayed return, Unit 1 integration, load, boredom, and attrition. It is not
an efficacy trial and cannot prove the complete course.

Start with `START_HERE_AR.md`, then use `PROTOCOL.md`, `FACILITATOR_CHECKLIST.md`,
`success-thresholds.json`, `progression-record.schema.json`, and
`ANALYSIS_RUNBOOK.md`. The paired de-identified observer instrument is
`prototype/first-ten/observer.html`.

No real session may begin until all ten rendered explanation videos have been listened
to and approved against their transcripts. The current text interface is for content
review and facilitator rehearsal only.

The observer creates or updates one longitudinal JSON record without names, raw
answers, free text, audio, or video. Individual records stay outside this repository.
