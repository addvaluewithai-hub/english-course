# Local lesson videos

Place optional rendered lesson videos here using the exact lesson ID:

- `U1-L01.mp4` through `U1-L09.mp4`
- `U2-L01.mp4`

The learner experience checks only the current lesson. If its file is missing, it shows
a clear video placeholder and lets the reviewer continue as if the video was watched.
Video files are local test assets and are not required by the repository source contract.
