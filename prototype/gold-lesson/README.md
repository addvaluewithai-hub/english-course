# Gold Lesson Prototype

Open `index.html` in a modern browser. No build, server, account, microphone, network,
or database is required.

- Default: teach-back variant.
- Omit comparison: append `?variant=omit` to the URL.
- Browser speech uses the device's installed English voice and is a prototype only.
- The text checker confirms task components; it does not assign real speaking mastery.

The first step is now a one-teacher video placeholder. All comprehension, application,
planning, coaching, and mastery interaction starts after it. The paste-ready Gemini TTS
package lives in `gold/introduce-yourself/video/`.

The prototype tests the revised lesson flow before production media or architecture.
Content authority remains in `gold/introduce-yourself/`.
