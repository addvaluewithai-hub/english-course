## Coherence critique

- Visual reading keeps referent matching as one judgment across familiar objects,
  people, and animals; it does not turn the compound source wording into separate facts.
- Spoken object identification merges questions and descriptions only because both are
  equivalent clues in one visible selection task.
- Object feature exchange keeps colour, size, and count in one bounded information gap;
  object presentation, position description, and home-information exchange remain
  separately assessable.
- Written object description and room-position description remain separate because
  they have different referents, task products, and valid fresh variants.
- Home prompts permit safe fictional answers and avoid assumptions about ownership,
  wealth, room count, family structure, or private living conditions.
