# Start Here

This is the active curriculum-design workspace. `main` is the canonical branch.

## Read order

1. `CURRENT_STATE.md`
2. `docs/LEVEL_CURRICULUM_DESIGN_PLAYBOOK_V1.md`
3. `curriculum/levels/<current-level>/manifest.json`
4. `curriculum/levels/<current-level>/exit_contract.json`
5. The current level's `design-review/` stages in order.
6. The immediately previous locked level only when prerequisite/retrieval evidence is needed.

## Current working rule

Do not infer a unit count, lesson count, semantic role, mastery requirement or productive-control obligation from raw source rows alone. Human curriculum decisions are authoritative; automation may expand, count, reconcile and validate them.

## Historical material

The complete pre-cleanup tree is preserved on:
`archive/level-source-of-truth-v1-2026-09-27`

Do not use that branch for active work. Consult it only when tracing provenance or an old decision.

## Never do silently

- Reopen a locked lower level.
- Treat one source row as one lesson.
- Treat coverage as mastery.
- Put new required content into a transfer/retrieval slot.
- Change exact source ownership without updating lifecycle and semantic evidence.
- Copy a previous level's unit/lesson count into the current level.
