# A1 Pronunciation and Intelligibility Ownership v1

Status: exact pronunciation pass accepted; final lesson placement remains open.

## Result

- 20 high-impact targets cover all 10 progression strands.
- All 54 current pronunciation-target candidates have exact owners.
- All 12 Arabic-learner risks have a disposition; none is treated as universal.
- General American broad IPA is a modelling reference only. Success is intelligibility plus successful repair.
- Accent removal, native imitation, and natural-rhythm mastery are explicitly excluded.

## Target inventory

### Letter names and spelling-sound verification (`a1_pronunciation.spelling_sound_verification`)

Strand: `pronunciation.sound_perception`. Control: `receptive_and_productive`.

Focus: Recognise the English letter name and check a heard model or IPA for irregular high-value spellings rather than applying one fixed letter-sound rule.

Examples: A /eɪ/; E /iː/; I /aɪ/; G /dʒiː/; J /dʒeɪ/; name /neɪm/; phone /foʊn/; eight /eɪt/; one /wʌn/

Introduce in: understand_spoken_contact_details. Recycle in: exchange_personal_details_orally, check_in_at_a_hotel.

Mastery: Hear a fresh key word, select its matching written form, then repeat or spell it when misunderstood.

Tolerance: Accept any stable intelligible variety; require repair only when the target distinction or key detail is lost.

Boundary: No full phonics or spelling-to-sound system is promised at A1.

Mastery: Record a fresh slowly spoken name plus digit sequence, then confirm the grouping accurately.

Tolerance: Accept any stable intelligible variety; require repair only when the target distinction or key detail is lost.

Boundary: Fast unscripted segmentation and unfamiliar proper names remain later or repair-supported.
