# Unit 1 production plan

Status: complete for the authored source packages. Rendered provider media remains a
separate generation-and-listening pass using the approved files.

## Authoring order

1. Freeze `U1-L01` as the reference package; only fix verified defects.
2. Author `U1-L02` to test listening comprehension of a fresh introduction.
3. Author `U1-L03` to extend the same details into a two-way spoken exchange.
4. Author `U1-L04` around accurate name and phone-number listening.
5. Author `U1-L05` before the form lesson so learners first locate labelled details.
6. Author `U1-L06` as accurate transfer into a simple form.
7. Author `U1-L07` as independent short profile writing.
8. Author `U1-L08` as a fresh written request-and-reply exchange.
9. Build the three-station unit mastery mission only after lesson-level checks pass.

## Required package per lesson

- source packet copied from the approved candidate without rewriting source evidence;
- one-teacher video scene, sample context, transcript, SSML, IPA, and captions;
- post-video comprehension and applied questions;
- guided practice, personal use, bounded correction, and fresh mastery task;
- delayed review item and accessibility text equivalent;
- automated checks plus Arabic-English human review.

## Production control

Complete one lesson package and validate it before generating the next lesson's final
audio or video. Transcript drafting may overlap, but media approval stays sequential so
a discovered voice, pacing, dialect, or exercise issue is not multiplied across the unit.
