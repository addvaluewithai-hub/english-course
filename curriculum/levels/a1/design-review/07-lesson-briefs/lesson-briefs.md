## Global authoring rules

1. Source record ≠ separate teaching object.
2. One primary learner performance per instructional lesson.
3. Foreground only language needed for that performance; other assigned records may enter as supported exposure.
4. Broad lexical sets = active core + supported recognition + later retrieval; no vocabulary dumps.
5. Multiple EGP rows may describe one usable system; no one-rule-one-slide grammar syllabus.
6. Chunks before unnecessary grammar explanation.
7. Pronunciation attaches to actual use and prioritises intelligibility.
8. Transfer lessons introduce **no hidden new required system or content**.
9. Fresh retrieval changes the prompt/context; it is not model repetition.
10. Mastery evidence cannot be copied from a complete model.
11. Receptive capabilities must remain genuinely receptive where the source requires reception; productive support must not erase the reception target.
12. If real authoring cannot fit naturally, reopen the architecture rather than rush or hide content.

Load notation throughout: **abilities / phrases / grammar / words / pronunciation = total source introductions**. A load count is not a prescription to teach that many isolated items.
