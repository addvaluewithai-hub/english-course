## Critic questions to resolve

### CQ-01 — Numbers family breadth
`C14 Handle basic numbers, quantities, times and dates` currently groups several functional numeric uses. Challenge whether this is one coherent capability family or should be split into:
- numbers/quantity/number strings; and
- time/dates/time references.

Do not split merely because the source has many records; split only if learning/assessment tasks differ enough to justify it.

### CQ-02 — Introduction family breadth
`C02 Meet and introduce people` combines:
- understanding an introduction;
- introducing self;
- introducing another person;
- responding to an introduction.

Challenge whether one family with four required branches is clearer than 2–3 separate final capabilities.

### CQ-03 — Personal-information fragmentation
Current map keeps `C03 personal info`, `C04 family/friends`, `C05 home/residence`, and `C06 possessions` separate.

Challenge whether this is useful task separation or unnecessary fragmentation. A merge is acceptable only if phrase/grammar/assessment mapping can preserve each content boundary without creating one overloaded mega-capability.

### CQ-04 — Instructions vs directions
Current map keeps:
- `C17 Follow simple instructions/procedures`; and
- `C18 Ask for and follow simple directions`.

The distinction is purposeful (procedural/command language vs spatial route navigation). Challenge it after phrase/grammar mapping, not on labels alone.

### CQ-05 — Transaction granularity
Current map keeps general prices/shopping plus food ordering, transport tickets, and hotel check-in as separate capabilities (`C22–C25`).

Challenge whether these should instead become one transaction family with mandatory task branches. They must not be merged if doing so allows one service scenario to stand in for all the others at assessment.

### CQ-06 — Weather
`C13 Describe basic weather` is based on a clear source objective but may be too small to deserve top-level capability status. Phrase/grammar review should test whether it naturally embeds under description/routine/planning without becoming invisible.

### CQ-07 — Generic information questions
`C20 Ask for basic information` is cross-cutting. Challenge whether it adds a necessary guarantee (learner initiates questions) or duplicates concrete question-asking already required in objects/personal-info/quantity/directions.

### CQ-08 — Supporting mechanics
Check that marking a source objective as `SUPPORTING` never weakens it. Slow/clear input conditions, question comprehension, spelling, punctuation, capitalisation, copying/repetition, and intelligibility must later appear as explicit design/assessment constraints.

## Lock criterion for Stage 01

Stage 01 can be marked **LOCKED** only when:

- all critic questions are resolved or explicitly deferred to phrase/grammar evidence;
- final capability count/structure is accepted;
- every one of the 119 required source abilities remains traceable to either a final capability or a named cross-cutting requirement;
- no unit/lesson count has been used as a reason for merging or splitting abilities.
