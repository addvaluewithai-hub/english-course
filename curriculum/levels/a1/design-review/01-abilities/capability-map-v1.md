# A1 Capability Map v1 — Manual Consolidation

Status: **READY FOR CRITIC — NOT LOCKED**  
Basis: manual reading and disposition of all **119/119** required A1 abilities in `manual-review-log.md`.

This file is the consolidated output of Stage 01. It is **not** a lesson map. A capability may require several lessons, and one lesson may support several capabilities.

## Consolidation rules used

1. Merge duplicate/near-duplicate source objectives when the learner performance and success condition are materially the same.
2. Keep reception/production/interaction evidence visible inside a capability even when the semantic purpose is shared.
3. Do not create a capability for a mere delivery condition or mechanic (e.g. slow speech, punctuation, repetition).
4. Keep distinct real-world tasks separate when success conditions differ (hotel check-in ≠ ticket purchase ≠ food ordering).
5. Allow one source objective to support more than one capability when it explicitly contains multiple performances.

# Cross-cutting requirements — active but NOT standalone capabilities

These source abilities remain curriculum requirements and must be enforced inside tasks/assessments, but they do not justify their own final capability or lesson.

### Receptive processing / A1 input conditions
Review rows: **7, 11, 12, 14, 16, 25, 29, 33, 39, 43, 64**.

Requirements include:
- short/simple/familiar language;
- slow/clear/carefully articulated speech where source-evidenced;
- visual support where source-evidenced;
- ability to recognise key familiar words/phrases and basic facts inside purposeful tasks.

### Spoken reproduction / intelligibility support
Review rows: **66, 70**.

Requirement: repeat/read familiar short language intelligibly enough to support learning and communication; not a final communicative endpoint.

### Writing mechanics and spelling
Review rows: **102, 103, 106, 109, 113, 114**.

Requirements:
- copy simple language when needed;
- basic capitalisation;
- basic punctuation;
- spell common names, greetings, jobs and other taught high-frequency items to the required A1 standard.

### Question comprehension/initiation
Review rows: **16, 21, 64, 92(part)** plus domain-specific question abilities.

Requirement: lessons must not only train answers. The learner must both understand common basic questions and initiate basic information questions in multiple final capabilities.
