# Level Source of Truth v1

This directory is the curriculum foundation for A1-C2. Each level owns a reviewed
inventory before lesson design.

Rules:
- Sources are evidence; these reviewed level files are the course source of truth.
- Lessons consume inventory items. They do not invent required level scope.
- Every included item must retain source provenance and a review status.
- Exclusions and deferrals must be explicit.
- Mastery/retention requirements belong in `exit_contract.json`.
- Existing lesson packages are not changed by this workstream until a later mapping audit.

Initial source roles:
- Words: Oxford 3000/5000 through C1; GSE Vocabulary is the planned C2 completion source.
- Phrases: Oxford Phrase List through C1; GSE Vocabulary phrases/collocations are the planned C2 completion source.
- Grammar: English Grammar Profile, cross-checked with Pearson GSE Grammar.
- Abilities: CEFR Companion Volume and Pearson GSE Adult General English objectives.
- Pronunciation: reviewed course pronunciation strands plus level-performance evidence.

Status: scaffolded. Inventory population and independent validation are still required.
