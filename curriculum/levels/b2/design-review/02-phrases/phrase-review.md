## Home-code legend

Capability homes reuse Stage 1:

- `C01–C07`: reading/listening reception families
- `C08`: detailed spoken description / narrative / explanation / procedure
- `C09`: spoken viewpoint / argument / evaluation
- `C10`: spoken probability / speculation / cause / hypothetical
- `C11`: collaborative discussion / conversation management
- `C12`: oral problems / complaints / negotiation / resolution
- `C13`: formal discussion / interview / survey / presentation Q&A
- `C14`: relay / paraphrase / summarize / facilitate
- `C15`: detailed descriptive / explanatory / procedural / narrative writing
- `C16`: written argument / evaluation / source-informed synthesis
- `C17`: correspondence / audience relationship
- `C18`: reports / reviews / extended functional genres

Cross-cutting semantic homes:

- `X-DISCOURSE`: linking, sequencing, topic framing, concession, reformulation, textual organization
- `X-STANCE`: opinion, certainty, concern, preference, evaluation
- `X-PRAGMATICS`: interactional formula, emphasis, softening, approximation, rhetorical effect
- `X-REGISTER`: formal/informal or audience-sensitive usage
- `X-LEXICAL-CONTENT`: content-bearing phrase whose topic/sense must not create a fake capability

`G3` in a boundary note means the phrase has a grammar interface that must be reconciled in Stage 3; the phrase itself does not license the broader grammar system.

## Architecture feedback from phrase evidence

### Stage-1 capability architecture

**No new top-level capability family is required by the phrase evidence.** The 18-family Stage-1 candidate remains coherent.

Phrase evidence particularly strengthens these Stage-1 families:

- `C09` / `C16`: argument, evidence, concession, balanced viewpoints and evaluation;
- `C08` / `C15`: detailed explanation, description, process, relation and factual reporting;
- `C11`: stance, topic movement and interactional management;
- `C12`: difficulty/problem handling and solution language;
- `C14`: summarizing, reformulating and relaying;
- `C18`: formal organization/reporting language.

The inventory also confirms that lexical themes such as human rights, mental health, quality of life, investment, role models and legal language must **not** be turned into capability families merely because phrases share a topic.

### Cross-cutting refinements

Stage 2 adds emphasis, not new top-level abilities, to three cross-cutting interfaces already implicit in Stage 1:

1. **Concession/condition framing** inside `X-DISCOURSE` (`as long as`, `despite the fact that`, `in spite of`, `no matter`, `whether or not`).
2. **Temporal/process framing** inside `X-DISCOURSE` (`at present`, `at some point`, `by now`, `ever since`, `prior to`, etc.).
3. **Approximation/degree/register** split across `X-PRAGMATICS` and `X-REGISTER` (`a bit of a`, `more or less`, `or so`, `pretty much`, `loads of`).

These are cross-cutting resources, not independent units.
