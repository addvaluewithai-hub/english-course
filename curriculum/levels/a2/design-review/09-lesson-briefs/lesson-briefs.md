# A2 Lesson Authoring Briefs — Milestone 4

Status: **IN PROGRESS — MANUAL AUTHORING CONTRACTS; NOT LESSON SCRIPTS**  
Level: **A2**  
Locked architecture: **12 units / 83 lesson slots**  
Prerequisite: Milestone 3 semantic/mastery lock + Stage 08.5 role-aware reconciliation closed.

These briefs translate the locked curriculum into lesson-authoring contracts. They do **not** authorize delivery/media production and do not turn source-row counts into teaching-object counts.

## Authoring rules

1. One primary communicative/evidence outcome per lesson. Integrated skills are allowed only when they serve that outcome.
2. Foreground only language that the locked semantic role requires for productive/interactive control. Receptive/contextual items may support input but must not become hidden production obligations.
3. Grammar systems are taught through the performance. Multiple EGP rows inside one reviewed system are not multiple grammar lessons.
4. Formulaic chunks are taught as usable routines unless canonical evidence supports broader generative control.
5. A1 carry-forward is retrieved, not re-taught as new A2 inventory.
6. Every lesson should contain fresh use of prior language where the Stage-06 lifecycle requires it; unit-end transfer uses changed context and reduced model support.
7. Pronunciation is embedded as an intelligibility/interaction constraint, not a separate accent target.
8. If a brief contradicts the locked semantic role or lifecycle, reopen the relevant decision explicitly and rerun audits. Do not silently override the lock.

# Unit 1 — From A1 Contact to A2 Exchange

**Unit outcome:** move from isolated A1 social routines to short A2 exchanges that can be opened, sustained, repaired, transferred to phone/message channels and followed up with linked personal information.

## U1-L01 — Reconnect and sustain simple small talk

- **Primary outcome:** open, sustain briefly and close a familiar face-to-face exchange while showing interest and understanding.
- **Foreground:** greeting/address routines, conversation opening/closing, fixed interest signals, `greet`, `welcome`; A1 wellbeing/social language is retrieval only.
- **Receptive/contextual:** simple everyday conversation conducted slowly/clearly; small-talk recognition; non-core social labels remain input breadth.
- **Embedded support:** sound perception/word recognition; slower speech/reformulation remains an allowed A2 condition.
- **Learning shape:** notice a short exchange → identify opening/maintenance/closing moves → controlled substitutions → two-turn extensions → partner exchange with one changed personal detail.
- **Evidence task:** meet a new partner/profile, sustain a short exchange without copying a complete model, then close appropriately.
- **Do not:** teach a broad “small-talk vocabulary list” or require every receptive social word in production.

## U1-L02 — Give a linked personal/background profile

- **Primary outcome:** give and write a short linked profile covering home/family, education/job and limited personal history.
- **Foreground:** bounded personal-profile language; `apply for`, `at the age of…`, `make money`; active core such as `adult`, `couple`, `guest`, `kid`, `marry`, `nearly`, `teenage` only where natural.
- **Receptive/contextual:** extra family/profile breadth such as `twin`; recognise basic personal/family information in input.
- **Embedded support:** reference-building/function words and pronoun substitution; avoid teaching G39 rows as separate grammar points.
- **Learning shape:** retrieve A1 personal facts → combine two facts → add background/time relation → build a 4–6 sentence profile → convert spoken profile to a short written profile.
- **Evidence task:** produce a short profile for a new profile card/site prompt using linked sentences rather than isolated fields.
- **Do not:** turn support words (`according to`, pronoun/reference items, etc.) into independent vocabulary targets.

## U1-L03 — Ask about another person's background

- **Primary outcome:** conduct a short background interview and expand answers enough to create a simple profile of another person.
- **Foreground:** core yes/no + wh-question formation needed for background/work/education; active lexis such as `background`, `boss`, `divorced`, `earn`, `education`, `relationship`, `training`, `working`; `in business` as a chunk.
- **Receptive/contextual:** extra occupation/subject labels support interview profiles but are not universal output obligations.
- **Embedded support:** G10/G40 are treated as **two bounded question systems**, not six grammar objectives. Expanded indirect/alternative/negative-question uses stay later per Stage 08.5.
- **Learning shape:** read/listen to a short profile → derive useful questions → controlled question/answer pairs → follow-up question → interview → brief third-person summary.
- **Evidence task:** interview a new partner/profile and report 4–6 linked facts accurately.
- **Do not:** front-load the full A2 question repertoire or run a decontextualised auxiliary-verb lesson.

## U1-L04 — Handle a basic personal phone call

- **Primary outcome:** identify self/intended person, answer simple questions and close a familiar personal phone call.
- **Foreground:** phone opening/identification/closing routines only; no new active vocabulary obligation.
- **Receptive/contextual:** recognise intended person and specific information in a short simple call; `voice` remains contextual.
- **Embedded support:** sentence prominence/rhythm + connected speech for intelligibility and phone listening.
- **Learning shape:** distinguish face-to-face vs phone openings → recognise intended person → controlled call skeleton → short unscripted call with changed caller/person details.
- **Evidence task:** complete a short phone call successfully with one information exchange and an appropriate close.
- **Do not:** use this slot as a home for general vocabulary or teach phone technology vocabulary.

## U1-L05 — Leave and take a simple phone message

- **Primary outcome:** leave/take a short factual phone message and repair one missing/unclear detail.
- **Foreground:** message-taking/leaving routines, confirmation, repetition/clarification on the phone; times/dates/prices as retrieval rather than new systems.
- **Receptive/contextual:** extract key factual information from a short recorded message and recognise confirmation routines.
- **Embedded support:** `make a mistake` is support language, not a separate production target.
- **Learning shape:** listen for who/what/when → note key facts → controlled message frame → add clarification request → pair message relay.
- **Evidence task:** receive a new message with one unclear detail, repair it, and pass the message on accurately.
- **Do not:** judge success by verbatim transcription; meaning and key-detail accuracy matter more.

## U1-L06 — Repair and confirm in a familiar exchange

- **Primary outcome:** keep a familiar exchange working by asking for repetition/clarification, checking meaning and confirming details.
- **Foreground:** `I mean`, `make sense`, `make sure`, `write sth down`, simple check/clarify routines; question-tag resources only in bounded repair/checking use.
- **Receptive/contextual:** recognise common clarification/checking expressions; `communicate`/`expression` remain contextual rather than output requirements.
- **Embedded support:** chunking, pausing, monitoring and pronunciation repair; slow/clear repetition remains an A2 support condition.
- **Learning shape:** notice breakdown → identify repair move → practise specific repair types → information-gap with planted ambiguity → rephrase/confirm.
- **Evidence task:** resolve two bounded misunderstandings in a familiar task without teacher-supplied wording.
- **Do not:** turn question tags into a broad grammar chapter or require meta-language about communication.

## U1-L07 — Fresh contact transfer

- **Primary outcome:** integrate contact, background exchange, phone/message handling and repair in a changed context.
- **Foreground:** no planned new semantic teaching; retrieve Unit 1 productive/formulaic language.
- **Receptive/contextual:** new profile/contact details should contain some unfamiliar-but-supported breadth.
- **Embedded support:** intelligibility and repair conditions from U1-L04/L06.
- **Learning shape:** new profile stimulus → brief face-to-face exchange/interview → short phone/message follow-up → partner relay.
- **Evidence task:** complete the contact chain with accurate key details and at least one successful clarification/confirmation move.
- **Do not:** provide a complete model or pre-fill the learner's questions/answers.

### Unit 1 rolling critic

- The seven slots remain coherent and no split is justified.
- U1-L03 is intentionally protected from expanded question forms; authoring must keep the interview performance primary.
- U1-L04 remains intentionally zero-active-lexis so phone mechanics are not obscured by vocabulary load.
- U1-L05 and U1-L06 are distinct: message relay vs general repair/confirmation.

# Unit 2 — People and Everyday Lives

**Unit outcome:** produce richer descriptions of people and everyday life, with personality/feelings, routines, interests, work/study and abilities kept as distinct performances.

## U2-L01 — Describe appearance and clothes

- **Primary outcome:** understand and give a short description of someone's physical appearance/clothing.
- **Foreground:** productive core such as `appearance`, `attractive`, `clothing`, `suit` plus the required description patterns; use a small active clothing/appearance core.
- **Receptive/contextual:** broader clothing/appearance labels (`belt`, `curly`, `fashion`, `jewellery`, `pants`, `pocket`, `sock`, `tie`, etc.) stay recognition breadth unless naturally reused.
- **Embedded support:** consonant clarity for description intelligibility.
- **Learning shape:** identify person from input → contrast core descriptors → guided description → information-gap identification → short written description.
- **Evidence task:** describe a new person well enough for a partner to identify them from several options.
- **Do not:** convert the receptive clothing set into a memorisation list.

## U2-L02 — Describe personality and feelings

- **Primary outcome:** describe personality/emotional state and give a brief reason where required.
- **Foreground:** a controlled active core of personality/feeling adjectives (`creative`, `helpful`, `intelligent`, `lazy`, `nervous`, `polite`, `rude`, `serious`, `worried`, etc.) plus `worried about…`; G03 functions as one adjective/linking system.
- **Receptive/contextual:** additional emotion/personality breadth supports input; not every adjective becomes independent output evidence.
- **Embedded support:** adjective degree/predicative/linking-verb rows are one bounded system; pronunciation should support adjective clarity, not become a separate segment.
- **Learning shape:** infer feeling/personality from short situations → pair adjective + reason → contrast two people → short spoken/written description.
- **Evidence task:** respond to a new profile/situation with a 4–6 sentence description including at least one brief reason.
- **Do not:** teach seven EGP rows as seven rules or demand synonym-heavy adjective production.

## U2-L03 — Describe routines and frequency more precisely

- **Primary outcome:** give a linked account of a routine with clearer frequency/time detail than A1.
- **Foreground:** routine/frequency core, G07/G38 in their reviewed routine/question uses, chunks such as `again and again`, `look after…`, `work out`; active core includes `everyday`, `regular`, `typical`, `sleep`, `wash`, etc.
- **Receptive/contextual:** extra routine/activity breadth supports listening/reading.
- **Embedded support:** cohesion/time-linking supports a connected account; do not turn the lesson into a present-simple recap.
- **Learning shape:** retrieve A1 routine → add frequency/sequence → compare two routines → ask a follow-up → give a linked routine account.
- **Evidence task:** describe a new person's routine from notes/visuals and answer follow-up questions.
- **Do not:** reteach all A1 daily-routine language as new.

## U2-L04 — Talk about hobbies, interests and preferences with reasons

- **Primary outcome:** state a preference/interest and support it with a short reason or limitation.
- **Foreground:** `a bit`, `all the time`, `care about…`, `find it difficult to…`, `it depends`, selected interest chunks; G29/G44 only in the functions required here.
- **Receptive/contextual:** broad hobby/content vocabulary may appear in input without becoming universal active obligations.
- **Embedded support:** simple reason-giving and stance; keep suggestion/advice functions for Unit 4.
- **Learning shape:** preference choice → reason frame → contrast two interests → partner mini-interview → brief recommendation/choice response without drifting into U4 suggestion language.
- **Evidence task:** discuss 2–3 unfamiliar activity options, state preferences and give short reasons.
- **Do not:** turn `science fiction` or hobby labels into a topic list to memorise.

## U2-L05 — Talk about work/study duties and everyday activity

- **Primary outcome:** describe current work/study context, duties and everyday activity in simple linked language.
- **Foreground:** core work/study lexis such as `apply`, `department`, `employ`, `fail`, `mark`, `role`, `succeed`; chunks `give sth up`, `take part`; G37 in its bounded reviewed use.
- **Receptive/contextual:** profession/subject/workplace breadth supports profiles and dialogues.
- **Embedded support:** word stress/syllable clarity for work/study vocabulary; generic “talk about everyday things” remains a quality constraint.
- **Learning shape:** read/listen to work/study profile → identify role/duty → build own/third-person account → compare current activity → short Q&A.
- **Evidence task:** give and answer questions about a new work/study profile with 4–6 linked details.
- **Do not:** make every profession/subject an active target.

## U2-L06 — Talk about skills and abilities

- **Primary outcome:** ask about and describe everyday skills/abilities, including simple written statements.
- **Foreground:** ability system G27 in the reviewed A2 function; `able to`, `do well`, `give up`, `these days`, `impossible`; everyday activity language serves the ability claim.
- **Receptive/contextual:** the noun `ability` itself remains receptive; additional activity labels may be supported.
- **Embedded support:** keep permission/request modal meanings out of this lesson.
- **Learning shape:** skill prompts → ask/answer ability questions → add degree/result → compare two people → write short skill profile.
- **Evidence task:** conduct a mini skills interview and produce a short profile of what the person can/cannot do well.
- **Do not:** teach modal polysemy or permission here.

## U2-L07 — Fresh person-profile transfer

- **Primary outcome:** integrate appearance/personality/routine/interests/work/skills into one new linked person profile.
- **Foreground:** no planned new semantic teaching; retrieve Unit 2 active systems selectively.
- **Receptive/contextual:** new profile should include supported lexical breadth so success depends on meaning, not memorised wording.
- **Embedded support:** reference-building to avoid repeated nouns; consonant/vowel/word-stress constraints remain intelligibility support.
- **Learning shape:** gather information from a new person/profile → select relevant details → interview/follow-up → spoken or written linked profile.
- **Evidence task:** create a coherent profile with at least three Unit 2 domains and accurate reference to the person.
- **Do not:** require every Unit 2 lexical item in one output.

### Unit 2 rolling critic

- U2-L02 has high raw/active density, but the brief caps it to a **controlled adjective core + one linking system**; receptive breadth must stay receptive.
- U2-L04 must remain preference/reason work, not drift into suggestions/advice.
- U2-L05 and U2-L06 stay distinct because duties/activity and ability/control have different evidence conditions.
- No lesson split is justified after semantic compression.

# Unit 3 — Homes, Things, Possessions, and Comparison

**Unit outcome:** extend A1 home/object language into richer description, ownership/use/reference and practical comparison/choice.

## U3-L01 — Describe a home/room with richer detail

- **Primary outcome:** describe a room/home with location, furniture and quantity detail.
- **Foreground:** `at the top`, `in the middle`, `on the wall`; productive home core (`bin`, `cooker`, `furniture`, `oven`, `roof`, etc.); G45 `there is/are` extensions as one bounded system.
- **Receptive/contextual:** extra object/home labels remain recognition breadth.
- **Embedded support:** demonstratives/reference and noun-phrase expansion support description; they are not separate foreground grammar.
- **Learning shape:** identify room from description → map position phrases → guided room description → information-gap room reconstruction → short written description.
- **Evidence task:** describe an unfamiliar room/home image accurately enough for a partner to reconstruct key layout/features.
- **Do not:** explain eight support-grammar rows independently.

## U3-L02 — Describe objects, materials, use and ownership

- **Primary outcome:** describe a familiar object/possession by material, appearance, location/use and ownership.
- **Foreground:** `be made of`, `belong to`, `close to`, `on the ground`, `on top of`; active object/material core (`bright`, `cupboard`, `empty`, `material`, `owner`, `possession`, `shape`, `soft`, `wood`, etc.).
- **Receptive/contextual:** broader material/object descriptors support identification tasks.
- **Embedded support:** noun phrase/reference expansion is support; formulaic ownership/use frames should be chunked.
- **Learning shape:** object identification → feature/material matching → ownership/use frame → mystery-object description → short favourite-object text.
- **Evidence task:** describe a new object/possession so a partner can identify it and state who it belongs to/what it is used for.
- **Do not:** make all 12 active words equally salient; choose a small reusable core per task and recycle the rest across examples.

## U3-L03 — Compare two people/things

- **Primary outcome:** make a practical comparison and justify a simple choice.
- **Foreground:** comparative systems G02/G08; `at least`, `everyone else`, `much better`; active comparison core (`better`, `worse`, `heavy/light`, `huge/enormous`, `narrow/wide`, `thin`, `weight`, etc.).
- **Receptive/contextual:** additional comparison/property breadth remains supported input.
- **Embedded support:** comparison is one communicative system, not ten adjective rules.
- **Learning shape:** notice contrast → build comparative sentence → compare on 2–3 criteria → ask/answer choice question → justify choice.
- **Evidence task:** compare two unfamiliar products/people/places and select one using multiple criteria.
- **Do not:** force every comparative adjective into learner output in one lesson.

## U3-L04 — Use superlatives to identify/choose

- **Primary outcome:** use bounded superlatives to identify the standout item/person/place in a familiar set.
- **Foreground:** G04 as one superlative system; small active property core (`best`, `deep`, `loud`, `unusual`, etc.) used only where communicatively relevant.
- **Receptive/contextual:** property breadth may support ranking input.
- **Embedded support:** `each one` and reference language help comparison sets.
- **Learning shape:** rank familiar set → state strongest/weakest feature → ask for choice → short reason.
- **Evidence task:** select the best/most suitable option from a new set and justify briefly.
- **Do not:** teach a superlative adjective inventory disconnected from choice.

## U3-L05 — Compare quantities and possessions

- **Primary outcome:** compare amounts/owned items and make a practical judgement.
- **Foreground:** `even more…`, `less than…`; active core including `belong`, `own`, `size`, `per`, `zero`, and quantity/comparison language already retrieved from A1.
- **Receptive/contextual:** low-frequency comparison nouns/adjectives may remain input support.
- **Embedded support:** quantifier systems remain bounded to practical comparison; service/shopping quantity work comes later in U5.
- **Learning shape:** quantity/ownership prompts → compare two inventories → ask/answer clarification → choose/decide.
- **Evidence task:** compare two unfamiliar possession/quantity profiles and explain one practical difference/choice.
- **Do not:** pre-teach U5 transaction language here.

## U3-L06 — Build clearer reference in descriptions

- **Primary outcome:** make a short description easier to follow by using reference rather than repeating the same noun.
- **Foreground:** the performance is clearer reference, not vocabulary; active object words scheduled here (`carpet`, `fridge`, `lamp`, `mirror`, `plastic`, `ring`, `sheet`, `towel`, `wooden`) serve description practice.
- **Receptive/contextual:** none of the reference-building infrastructure becomes an independent lexical target.
- **Embedded support:** relative clauses, demonstrative back-reference, pronoun substitution and noun-phrase expansion are quality constraints.
- **Learning shape:** compare repetitive vs clearer text → identify reference links → controlled rewrite → spoken description with monitored reference → peer reconstruction.
- **Evidence task:** describe a familiar object/room set for a partner using clear reference without repeated-noun overload.
- **Do not:** turn X09 into a standalone advanced relative-clause lesson.

## U3-L07 — Fresh compare-and-choose transfer

- **Primary outcome:** integrate description, ownership/reference and comparison to make a new choice.
- **Foreground:** no planned new semantic teaching; retrieve U3 systems selectively.
- **Receptive/contextual:** unfamiliar homes/products/places can contain supported descriptive breadth.
- **Embedded support:** reference-building + comparison clarity.
- **Learning shape:** inspect two new options → extract key features → compare → clarify one detail → choose and justify.
- **Evidence task:** spoken/written compare-and-choose response with clear reference and at least two comparison criteria.
- **Do not:** provide a complete comparison model or demand all U3 vocabulary.

### Unit 3 rolling critic

- U3-L02/U3-L03 remain high-ish lexical lessons, but each has one coherent performance; authoring must stage the active core across examples rather than present a flat list.
- U3-L06 is explicitly a **quality/reference** lesson, not a hidden grammar chapter.
- U3-L03 comparison and U3-L04 superlative choice stay separate because the learner evidence is different.
- No structural change to the 83-slot lock is required.
