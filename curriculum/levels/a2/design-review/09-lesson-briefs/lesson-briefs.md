# A2 Lesson Authoring Briefs — Milestone 4

Status: **IN PROGRESS — MANUAL AUTHORING CONTRACTS; NOT LESSON SCRIPTS**  
Level: **A2**  
Locked architecture: **12 units / 83 lesson slots**  
Prerequisite: Milestone 3 semantic/mastery lock + Stage 08.5 role-aware reconciliation closed.

These briefs translate the locked curriculum into authoring contracts. They do **not** authorize lesson/script/media production and do not treat source-row counts as teaching-object counts.

## Authoring rules

1. One primary communicative/evidence outcome per lesson; integrated skills only when they serve that outcome.
2. Foreground only locked productive/interactive language. Receptive/contextual items support input and must not become hidden production obligations.
3. Grammar is taught through the performance; multiple EGP rows inside one reviewed system are not separate grammar objectives.
4. Formulaic chunks are taught as usable routines unless canonical evidence supports broader generative control.
5. A1 carry-forward is retrieved, not re-taught as new A2 inventory.
6. Unit-end transfer uses changed context, reduced model support and fresh retrieval.
7. Pronunciation is an embedded intelligibility/interaction constraint, not an accent target.
8. If a brief contradicts the locked semantic role/lifecycle, reopen the decision explicitly and rerun audits.

# Unit 1 — From A1 Contact to A2 Exchange

**Unit outcome:** move from isolated A1 social routines to short A2 exchanges that can be opened, sustained, repaired, transferred to phone/message channels and followed up with linked personal information.

## U1-L01 — Reconnect and sustain simple small talk
- **Outcome:** open, sustain briefly and close a familiar face-to-face exchange while showing interest/understanding.
- **Foreground:** greeting/address routines, conversation opening/closing, fixed interest signals, `greet`, `welcome`; A1 wellbeing language is retrieval only.
- **Receptive/support:** slow/clear everyday conversation, small-talk recognition, sound perception.
- **Learning shape:** notice moves → controlled substitutions → two-turn extensions → partner exchange.
- **Evidence:** meet a new profile/person, sustain a short exchange and close appropriately.
- **Do not:** create a broad small-talk vocabulary list.

## U1-L02 — Give a linked personal/background profile
- **Outcome:** give/write a short linked profile covering home/family, education/job and limited history.
- **Foreground:** `apply for`, `at the age of…`, `make money`; selected profile lexis (`adult`, `couple`, `guest`, `kid`, `marry`, `nearly`, `teenage`).
- **Receptive/support:** extra profile/family breadth; reference-building/function words stay support.
- **Learning shape:** retrieve A1 facts → link facts → add background/time relation → short spoken/written profile.
- **Evidence:** produce a new profile-card/site response in linked sentences.
- **Do not:** make support pronouns/reference items separate vocabulary targets.

## U1-L03 — Ask about another person's background
- **Outcome:** conduct a short background interview and expand answers enough to profile another person.
- **Foreground:** core yes/no + wh-question formation; `background`, `boss`, `divorced`, `earn`, `education`, `relationship`, `training`, `working`; `in business`.
- **Receptive/support:** extra occupation/subject labels; G10/G40 are **two bounded question systems**, not six rules.
- **Learning shape:** profile input → derive questions → guided Q&A → follow-up → interview → third-person summary.
- **Evidence:** interview a new profile/person and report 4–6 linked facts.
- **Do not:** front-load the full A2 question repertoire; expanded question functions stay later.

## U1-L04 — Handle a basic personal phone call
- **Outcome:** identify self/intended person, answer simple questions and close a familiar personal call.
- **Foreground:** phone opening/identification/closing routines; intentionally **zero new active vocabulary**.
- **Receptive/support:** intended-person/specific-information listening; prominence/rhythm + connected speech.
- **Learning shape:** recognise call roles → controlled call skeleton → short unscripted changed-detail call.
- **Evidence:** complete one short call with an information exchange and appropriate close.
- **Do not:** use the slot for general or technology vocabulary.

## U1-L05 — Leave and take a simple phone message
- **Outcome:** leave/take a short factual message and repair one unclear detail.
- **Foreground:** message routines, confirmation, repetition/clarification; time/date/number language is retrieval.
- **Receptive/support:** extract key facts from recorded messages; `make a mistake` stays support.
- **Learning shape:** listen for who/what/when → note facts → message frame → clarification → relay.
- **Evidence:** receive a new message with one unclear detail, repair it, relay it accurately.
- **Do not:** require verbatim transcription.

## U1-L06 — Repair and confirm in a familiar exchange
- **Outcome:** keep a familiar exchange working through repetition, clarification, checking and confirmation.
- **Foreground:** `I mean`, `make sense`, `make sure`, `write sth down`, bounded check/clarify routines.
- **Receptive/support:** clarification recognition; chunking, pausing, monitoring, pronunciation repair.
- **Learning shape:** notice breakdown → classify repair move → practise → information-gap ambiguity → rephrase/confirm.
- **Evidence:** resolve two bounded misunderstandings without teacher-supplied wording.
- **Do not:** turn question tags into a broad grammar chapter.

## U1-L07 — Fresh contact transfer
- **Outcome:** integrate contact, background exchange, phone/message handling and repair in a changed context.
- **Foreground:** no planned new semantic teaching; retrieve Unit 1 selectively.
- **Receptive/support:** new profile/contact details with supported lexical breadth.
- **Learning shape:** new profile → exchange/interview → phone/message follow-up → relay.
- **Evidence:** complete the contact chain with accurate details and one successful repair move.
- **Do not:** provide a complete model or pre-filled questions.

### Unit 1 rolling critic
- U1-L03 remains interview-first, not grammar-first.
- U1-L04 remains zero-active-lexis by design.
- U1-L05 message relay and U1-L06 general repair remain distinct.
- No split/merge or semantic reopening required.

# Unit 2 — People and Everyday Lives

**Unit outcome:** produce richer descriptions of people and everyday life while keeping appearance, personality, routines, preferences, work/study and ability as distinct performances.

## U2-L01 — Describe appearance and clothes
- **Outcome:** understand/give a short appearance/clothing description.
- **Foreground:** small productive core such as `appearance`, `attractive`, `clothing`, `suit` plus required description frames.
- **Receptive/support:** broader clothing/appearance labels (`belt`, `curly`, `fashion`, `jewellery`, `pants`, `pocket`, `sock`, `tie`, etc.); consonant clarity.
- **Learning shape:** identify person → contrast descriptors → guided description → information-gap identification → short writing.
- **Evidence:** describe a new person well enough for partner identification.
- **Do not:** convert receptive clothing breadth into a memorisation list.

## U2-L02 — Describe personality and feelings
- **Outcome:** describe personality/emotional state and give a brief reason.
- **Foreground:** controlled adjective core (`creative`, `helpful`, `intelligent`, `lazy`, `nervous`, `polite`, `rude`, `serious`, `worried`, etc.) + `worried about…`; G03 as one linking/adjective system.
- **Receptive/support:** additional emotion/personality breadth.
- **Learning shape:** infer state from situation → adjective + reason → contrast people → short spoken/written description.
- **Evidence:** 4–6 sentence response to a new profile/situation including a brief reason.
- **Do not:** teach seven EGP rows as seven rules or demand synonym-heavy production.

## U2-L03 — Describe routines and frequency more precisely
- **Outcome:** give a linked routine account with clearer frequency/time detail than A1.
- **Foreground:** routine/frequency core; G07/G38 in reviewed uses; `again and again`, `look after…`, `work out`; `everyday`, `regular`, `typical`, `sleep`, `wash`.
- **Receptive/support:** extra routine/activity breadth; cohesion/time-linking.
- **Learning shape:** retrieve A1 routine → add frequency/sequence → compare routines → follow-up → linked account.
- **Evidence:** describe a new person's routine and answer follow-up questions.
- **Do not:** reteach the entire A1 routine inventory.

## U2-L04 — Talk about hobbies, interests and preferences with reasons
- **Outcome:** state a preference/interest and support it with a short reason/limitation.
- **Foreground:** `a bit`, `all the time`, `care about…`, `find it difficult to…`, `it depends`; G29/G44 only in required functions.
- **Receptive/support:** broad hobby/content vocabulary remains input breadth where appropriate.
- **Learning shape:** preference choice → reason frame → contrast interests → mini-interview → brief choice response.
- **Evidence:** discuss 2–3 unfamiliar activity options and justify preferences.
- **Do not:** drift into Unit 4 suggestion/advice language or create a hobby word list.

## U2-L05 — Talk about work/study duties and everyday activity
- **Outcome:** describe work/study context, duties and everyday activity in linked language.
- **Foreground:** `apply`, `department`, `employ`, `fail`, `mark`, `role`, `succeed`; `give sth up`, `take part`; G37 in bounded use.
- **Receptive/support:** profession/subject/workplace breadth; word stress/syllable clarity.
- **Learning shape:** profile input → identify role/duty → build account → compare activity → Q&A.
- **Evidence:** answer/give questions about a new work/study profile with 4–6 linked details.
- **Do not:** make every profession/subject an active target.

## U2-L06 — Talk about skills and abilities
- **Outcome:** ask about and describe everyday skills/abilities, including simple writing.
- **Foreground:** G27 ability use; `able to`, `do well`, `give up`, `these days`, `impossible`.
- **Receptive/support:** the noun `ability` and extra activity labels can remain input breadth.
- **Learning shape:** skill prompts → ask/answer → add degree/result → compare people → short skill profile.
- **Evidence:** mini skills interview + short profile of what someone can/cannot do well.
- **Do not:** mix permission/request modal meanings into this lesson.

## U2-L07 — Fresh person-profile transfer
- **Outcome:** integrate appearance/personality/routine/interests/work/skills in a new linked profile.
- **Foreground:** no planned new semantic teaching.
- **Receptive/support:** supported lexical breadth; reference-building avoids repeated nouns.
- **Learning shape:** gather → select → interview/follow-up → spoken/written linked profile.
- **Evidence:** coherent profile with at least three Unit 2 domains.
- **Do not:** require every Unit 2 lexical item in one output.

### Unit 2 rolling critic
- U2-L02 is capped to a controlled adjective core + one linking system despite high raw density.
- U2-L04 stays preference/reason, not suggestion/advice.
- U2-L05 duties/activity and U2-L06 ability remain separate evidence outcomes.
- No split/merge required.

# Unit 3 — Homes, Things, Possessions, and Comparison

**Unit outcome:** extend A1 home/object language into richer description, ownership/use/reference and practical comparison/choice.

## U3-L01 — Describe a home/room with richer detail
- **Outcome:** describe a room/home with location, furniture and quantity detail.
- **Foreground:** `at the top`, `in the middle`, `on the wall`; `bin`, `cooker`, `furniture`, `oven`, `roof`, etc.; G45 `there is/are` extension as one system.
- **Receptive/support:** extra home/object breadth; demonstratives/reference/noun-phrase expansion remain support.
- **Learning shape:** identify room → map position → guided description → room reconstruction → short writing.
- **Evidence:** describe an unfamiliar room/home so a partner can reconstruct key features.
- **Do not:** explain support grammar rows independently.

## U3-L02 — Describe objects, materials, use and ownership
- **Outcome:** describe an object/possession by material, appearance, location/use and ownership.
- **Foreground:** `be made of`, `belong to`, `close to`, `on the ground`, `on top of`; active core such as `material`, `owner`, `possession`, `shape`, `soft`, `wood`.
- **Receptive/support:** broader material/object descriptors; reference expansion stays embedded.
- **Learning shape:** identify object → feature/material match → ownership/use frame → mystery object → short favourite-object text.
- **Evidence:** describe a new object so partner identifies it and its owner/use.
- **Do not:** present all active words as a flat list.

## U3-L03 — Compare two people/things
- **Outcome:** make a practical comparison and justify a simple choice.
- **Foreground:** G02/G08; `at least`, `everyone else`, `much better`; comparison core (`better/worse`, heavy/light, huge/enormous, narrow/wide, thin, weight).
- **Receptive/support:** extra property breadth.
- **Learning shape:** notice contrast → comparative sentence → multi-criterion comparison → ask/answer → choose.
- **Evidence:** compare two unfamiliar options and select one using multiple criteria.
- **Do not:** force every comparative adjective into one output.

## U3-L04 — Use superlatives to identify/choose
- **Outcome:** use bounded superlatives to identify the standout option in a familiar set.
- **Foreground:** G04 as one system; small property core (`best`, `deep`, `loud`, `unusual`, etc.).
- **Receptive/support:** ranking/property breadth; `each one` and reference support.
- **Learning shape:** rank set → state standout feature → ask for choice → reason.
- **Evidence:** select best/most suitable option from a new set and justify briefly.
- **Do not:** teach a disconnected superlative adjective inventory.

## U3-L05 — Compare quantities and possessions
- **Outcome:** compare amounts/owned items and make a practical judgement.
- **Foreground:** `even more…`, `less than…`; `belong`, `own`, `size`, `per`, `zero`; prior quantity language retrieved.
- **Receptive/support:** lower-frequency comparison breadth; quantifier support remains bounded.
- **Learning shape:** compare inventories → clarify → choose/decide.
- **Evidence:** compare two unfamiliar possession/quantity profiles and explain one practical difference.
- **Do not:** pre-teach Unit 5 transaction language.

## U3-L06 — Build clearer reference in descriptions
- **Outcome:** make a short description easier to follow by using reference instead of repeated nouns.
- **Foreground:** performance is clearer reference; scheduled active object words (`carpet`, `fridge`, `lamp`, `mirror`, `plastic`, `ring`, `sheet`, `towel`, `wooden`) serve the task.
- **Receptive/support:** relative clauses, demonstrative back-reference, pronoun substitution and noun-phrase expansion are quality constraints.
- **Learning shape:** compare repetitive/clear text → identify reference links → rewrite → monitored spoken description → peer reconstruction.
- **Evidence:** describe a familiar object/room set with clear reference.
- **Do not:** turn X09 into an advanced relative-clause lesson.

## U3-L07 — Fresh compare-and-choose transfer
- **Outcome:** integrate description, ownership/reference and comparison to make a new choice.
- **Foreground:** no planned new semantic teaching.
- **Receptive/support:** unfamiliar options may contain supported descriptive breadth.
- **Learning shape:** inspect → extract → compare → clarify → choose/justify.
- **Evidence:** spoken/written compare-and-choose with clear reference and at least two criteria.
- **Do not:** provide a complete comparison model.

### Unit 3 rolling critic
- U3-L02/U3-L03 remain lexically dense but each has one coherent performance; active core must be staged across examples.
- U3-L06 stays a quality/reference lesson, not a hidden grammar chapter.
- Comparison and superlative choice remain distinct.
- No structural change required.

# Unit 4 — Requests, Opinions, Advice, and Everyday Social Action

**Unit outcome:** manage interpersonal action beyond A1 fixed requests while keeping request/permission/opinion/suggestion/advice/pragmatic reaction as separate learner outcomes.

## U4-L01 — Request, offer, borrow and lend
- **Outcome:** make/respond/refuse politely around immediate needs, borrowing/lending and simple offers.
- **Foreground:** C12 request/offer branch; `Let me…`; core lexis `borrow`, `offer`, `refuse`; G20/G27/G28 only in request/offer/willingness functions.
- **Receptive/support:** understand direct slow/clear requests; meta nouns such as `request` remain contextual.
- **Learning shape:** need scenario → request/offer choice → accept/refuse → borrow/lend exchange → changed-role information gap.
- **Evidence:** complete a new borrow/request scenario with an appropriate response/refusal.
- **Do not:** teach three modal systems as a table or pull permission/advice into this slot.

## U4-L02 — Ask for/give/refuse permission and express obligation
- **Outcome:** handle familiar permission and necessity/obligation exchanges.
- **Foreground:** `be allowed to…`, `have got to`; G24/G25 plus bounded modal-question support; `allow`, `permission`.
- **Receptive/support:** contextual rules/situation vocabulary; function-word/reference support stays embedded.
- **Learning shape:** classify allowed/not allowed/required → ask permission → grant/refuse → state obligation → short role-play.
- **Evidence:** resolve a new familiar situation containing one permission question and one obligation/necessity point.
- **Do not:** drift into full rules/instructions teaching; that performance belongs to U10.

## U4-L03 — Give an opinion and brief reason
- **Outcome:** state/evaluate an opinion and support it with a brief reason.
- **Foreground:** `believe in…`, `go for…`, `happy with…`, `the best thing`, `the important thing`; core evaluative lexis (`awful`, `choice`, `disagree`, `option`, `strange`, `surprised`, `worry`); G05/G23/G38 in stance/reason use.
- **Receptive/support:** broader evaluation language; discourse support remains integrated.
- **Learning shape:** evaluate options → agree/disagree → reason frame → compare views → short opinion response.
- **Evidence:** react to a new choice/problem with a clear opinion + reason and respond to another view.
- **Do not:** let the lesson become adjective memorisation or suggestion/advice practice.

## U4-L04 — Make and respond to suggestions
- **Outcome:** make, discuss and respond to simple suggestions collaboratively.
- **Foreground:** deliberately narrow repertoire: `if you want to`, `Why not…?`, `suggest`; bounded G27/G38 suggestion patterns.
- **Receptive/support:** `condition`/meta-question language remains contextual.
- **Learning shape:** identify suggestion → controlled pattern choice → accept/reject → discuss what to do next → mini planning problem.
- **Evidence:** solve a new two-person choice by making/responding to at least two suggestions.
- **Do not:** re-import opinion chunks or broad conditional/advice systems removed in Stage 08.5.

## U4-L05 — Ask for and give basic advice
- **Outcome:** ask for/give basic advice around familiar everyday problems.
- **Foreground:** `solution to…`; `alternative`, `consider`, `ideal`, `necessary`, `recommend`, `solution`, `solve`, `trouble`; G13/G27/G29 only in advice/hedging functions.
- **Receptive/support:** contextual problem vocabulary.
- **Learning shape:** problem input → ask for advice → choose advice frame → justify/rephrase → role swap.
- **Evidence:** respond to a new everyday problem with two bounded pieces of advice and a reason/condition.
- **Do not:** teach a modal/conditional inventory detached from the problem.

## U4-L06 — Handle apologies, excuses, compliments, encouragement and reactions
- **Outcome:** respond appropriately to short social/pragmatic moments and check understanding where needed.
- **Foreground:** `Come on!`, `I don't care`, `I'm afraid…`, `no way`, `Oh well`, `respond to…`; `all right`, `brilliant`, `complain`, `excellent`, `incredible`, `lovely`; bounded G10 exclamation/negative-question resources.
- **Receptive/support:** recognise simple excuses/reactions; X05 pragmatics + repair cross-link.
- **Learning shape:** identify social intent → match response → mini exchanges → tone/meaning contrast → spontaneous reaction rounds.
- **Evidence:** handle a sequence of 3–4 new social moments with an appropriate response and one understanding check.
- **Do not:** treat every reaction as interchangeable or turn this into generic vocabulary practice.

## U4-L07 — Fresh decision/problem-solving transfer
- **Outcome:** integrate opinion, suggestion/advice, request/permission and repair in a changed problem.
- **Foreground:** no planned new semantic teaching.
- **Receptive/support:** unfamiliar situation details; repair remains available if breakdown occurs.
- **Learning shape:** new problem → clarify constraints → exchange views → propose/advice/request → agree decision.
- **Evidence:** complete a partner decision task with a justified outcome and successful repair if needed.
- **Do not:** pre-script the decision path.

### Unit 4 rolling critic
- U4-L04 remains intentionally small after Stage 08.5; do not inflate it again.
- U4-L01 request/offer and U4-L02 permission/obligation remain separate despite shared modal forms.
- U4-L03 opinion, U4-L04 suggestion and U4-L05 advice must remain distinguishable in assessment.
- U4-L06 is pragmatic interaction management, not a miscellaneous review dump.

# Unit 5 — Shopping, Food, Quantities, and Everyday Services

**Unit outcome:** broaden A1 service language into more independent quantity/product/service exchanges and practical information use.

## U5-L01 — Ask about amounts and quantities
- **Outcome:** ask/answer practical questions about quantity/amount.
- **Foreground:** G17 as one countable/uncountable quantity system; `a couple of…`, `quite a lot`; `amount`, `count`, `least`, `per cent` where natural.
- **Receptive/support:** determiner/noun infrastructure G30/G31 stays embedded; price/payment words are contextual unless needed by the task.
- **Learning shape:** quantity recognition → ask/answer → container/measure retrieval → information-gap amounts.
- **Evidence:** obtain missing quantities for a new practical list/order.
- **Do not:** teach six support grammar rows as separate points.

## U5-L02 — Ask about and compare products
- **Outcome:** compare products on practical criteria and make a choice.
- **Foreground:** bounded comparison system; `a number of…`, `feel like…`, `I think so`, `save money`; `advantage`, `credit`, `double`, `less`, `quality`, `quantity`, `service` as task-serving core.
- **Receptive/support:** extra product/price descriptors remain contextual.
- **Learning shape:** read product details → ask missing information → compare 2–3 criteria → choose + brief reason.
- **Evidence:** select one of two unfamiliar products/services and justify the choice.
- **Do not:** turn this into a second Unit 3 comparison lesson; the success condition is product/service choice.

## U5-L03 — Order food and handle a simple menu exchange
- **Outcome:** understand a simple menu and complete a routine food/drink order.
- **Foreground:** food/service request routines, G17 quantity retrieval, `credit card`; small food-preparation core (`boil`, `oil`, `taste`, etc.) only as menu/context support.
- **Receptive/support:** menu breadth may exceed learner production.
- **Learning shape:** scan menu → clarify item/quantity → order → respond to server question → payment/detail close.
- **Evidence:** order from an unfamiliar simple menu with one clarification.
- **Do not:** make cooking vocabulary the main learning outcome.

## U5-L04 — Complete a shop transaction
- **Outcome:** state what is wanted, ask details/price, pay/respond and handle minor clarification.
- **Foreground:** `one or two`; transaction lexis such as `sale`, `store`, `tip`, `free`, `sir` only where useful.
- **Receptive/support:** broader shop/service vocabulary remains contextual.
- **Learning shape:** product need → detail/price question → transaction → clarification → close.
- **Evidence:** complete a changed shop scenario successfully without a complete model.
- **Do not:** require every scheduled word to appear in one transaction.

## U5-L05 — Handle post-office/bank/basic service exchange
- **Outcome:** complete a familiar direct service transaction in a changed setting.
- **Foreground:** `per hour`; small service core (`gift`, `save`, `stamp`) only when task-relevant; reuse request/quantity/payment language.
- **Receptive/support:** setting-specific service vocabulary can be supported.
- **Learning shape:** interpret service options → request → answer detail question → pay/confirm → close.
- **Evidence:** complete one unfamiliar-but-routine service exchange.
- **Do not:** create separate mini-courses for bank/post-office vocabulary.

## U5-L06 — Find information in menus, posters, price lists and service material
- **Outcome:** locate practical facts that directly support a service choice/transaction.
- **Foreground:** information-retrieval behaviour, not lexical production; active scheduled words (`bowl`, `fork`, `plate`, `spoon`, etc.) are used in practical material rather than drilled as a set.
- **Receptive/support:** predictable details, prices, times, conditions and item labels.
- **Learning shape:** scan → locate → cross-check → choose → relay information.
- **Evidence:** use two new practical sources to answer a service-choice problem.
- **Do not:** turn the slot into a kitchen-object vocabulary lesson.

## U5-L07 — Fresh routine-transaction evidence
- **Outcome:** integrate information retrieval, quantity/product choice and a routine service transaction with one repair.
- **Foreground:** no planned new semantic teaching.
- **Receptive/support:** changed products/details and one bounded misunderstanding.
- **Learning shape:** inspect source → decide → transact → repair → confirm outcome.
- **Evidence:** complete a new service scenario end-to-end.
- **Do not:** reuse the exact U5-L03/L04 script.

### Unit 5 rolling critic
- U5-L01 quantity grammar remains one system, not a determiner chapter.
- U5-L03 food/menu and U5-L04 shop transaction have different evidence outcomes.
- U5-L06 is information retrieval; lexical items are contextual carriers, not a hidden vocabulary dump.
- No structural change required.

# Unit 6 — Around Town, Directions, Travel, and Reservations

**Unit outcome:** integrate location/navigation with travel information and successful ticket/reservation/accommodation outcomes while keeping phone mechanics distinct from transaction success.

## U6-L01 — Describe/find places around town
- **Outcome:** describe/find familiar town locations using static spatial relations.
- **Foreground:** `a long way`, `get back`, `go away`, `go up`, `up and down`; place/location core (`bridge`, `direction`, `inside`, `position`, `side`, `square`, `tower`, `view`).
- **Receptive/support:** extra place vocabulary remains contextual.
- **Learning shape:** map identification → describe location → partner find-the-place → short route-preparation task.
- **Evidence:** locate several unfamiliar map places from spoken/written clues.
- **Do not:** drift into route-giving before U6-L02/L03.

## U6-L02 — Ask for directions and location
- **Outcome:** initiate direction/location questions and understand a simple route response.
- **Foreground:** `come back`, `get lost`, `go down`, `on the other side`; route core (`along`, `corner`, `distance`, `forward`, `outside`, `straight`, `upstairs`).
- **Receptive/support:** extra movement/place breadth; query initiation from prior units.
- **Learning shape:** destination problem → ask location → clarify start/end → follow short answer → partner map gap.
- **Evidence:** obtain enough information to identify/reach a new destination.
- **Do not:** require every movement/place word productively in one route.

## U6-L03 — Give and follow multi-step directions
- **Outcome:** give/follow a short ordered route accurately.
- **Foreground:** G09/G38 in route/sequencing use; `far away`, `get out`, `go down sth`, `the other side of…`; route core (`bottom`, `downstairs`, `ground`, `hill`, `lift`, `middle`, `parking`, `round`, `towards`).
- **Receptive/support:** sequencing/reference infrastructure remains embedded.
- **Learning shape:** route chunks → sequence steps → map dictation → give route → listener verifies.
- **Evidence:** guide a partner through a new multi-step route with one clarification point.
- **Do not:** turn route grammar into a generic imperative lesson.

## U6-L04 — Understand timetables, delays and transport information
- **Outcome:** extract places/times/dates/status information from practical transport sources.
- **Foreground:** `pick up`, `public transport`, `take off`; transport/digital core (`app`, `passenger`, `seat`, `underground`, `web`, etc.) as source-serving vocabulary.
- **Receptive/support:** timetable/status/detail language can exceed active production.
- **Learning shape:** scan/listen → locate departure/arrival/status → compare options → relay key facts.
- **Evidence:** choose a viable journey from unfamiliar transport information and explain key details.
- **Do not:** teach 13 transport words as a flat active list.

## U6-L05 — Buy a ticket and ask tourist-office information
- **Outcome:** complete a ticket/tourist-information exchange successfully.
- **Foreground:** travel transaction core (`airline`, `ride`, `ship`, `train`, `transport`, `van`, etc.) selectively; reuse quantity/price/request language.
- **Receptive/support:** broader vehicle/travel breadth remains contextual.
- **Learning shape:** state destination/need → ask options/detail → choose → ticket transaction → confirm.
- **Evidence:** complete a changed ticket/information scenario with correct key details.
- **Do not:** make transport-category naming the main assessment.

## U6-L06 — Handle hotel/accommodation details
- **Outcome:** understand accommodation details and complete simple check-in/out interaction.
- **Foreground:** `check in`, `check out`; accommodation/travel core (`book`, `collect`, `gate`, `guide`, `platform`, `route`, `stay`, `traveller`, `vehicle`) only where task-relevant.
- **Receptive/support:** broader travel labels can remain input breadth.
- **Learning shape:** read booking → verify details → check in → ask/answer one detail → check out/close.
- **Evidence:** handle a new simple accommodation booking/check-in scenario accurately.
- **Do not:** require all 14 scheduled active words in one hotel dialogue.

## U6-L07 — Make, change/cancel a reservation or appointment by phone
- **Outcome:** use phone mechanics to achieve a reservation/appointment outcome.
- **Foreground:** transaction outcome remains C11; phone mechanics from U1 are retrieval; selected travel/booking core (`coach`, `pack`, `railway`, `tour`, `wait`, etc.) only as scenario carriers.
- **Receptive/support:** new times/dates/options may be introduced in the prompt.
- **Learning shape:** call opening → state booking/change need → exchange details → repair/confirm → close.
- **Evidence:** make/change/cancel one unfamiliar reservation by phone with accurate final details.
- **Do not:** assess successful phone form without successful reservation outcome, or vice versa.

## U6-L08 — Fresh travel mission
- **Outcome:** integrate practical information extraction, navigation, transaction/reservation and repair in a new journey.
- **Foreground:** no planned new semantic teaching.
- **Receptive/support:** changed map/timetable/booking data.
